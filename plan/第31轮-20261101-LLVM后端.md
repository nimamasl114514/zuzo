## 风险与动作级闸门预设

- 计算闸：IR 行数、用例数、声明条数、内存统计一律脚本实算。
- 依赖闸：不引入 llir/llvm 等 Go 依赖，纯文本 IR 拼接；不装 LLVM 其余组件。
- 不可逆操作：删除 `cbackend/` 与 `nativecc/` 前先 `git commit` 断点（第30轮改动一并提交），保证可回滚。
- 子代理：一文件一所有者（expr/stmt/builtin/docs/tests 各自独立文件），不并发改同一文件；结果以落盘文件为准。

## 显式假设

1. 「不搞 C 语言后端」= 不再有 AST→C 源码的代码生成路径；运行时库仍以 C 实现、由 clang 编译为 obj 链接（等同于 libc 角色），文档中明确标注。
2. 语言语义以解释器为准；LLVM 产物必须与解释器逐字节一致（含 stdout/rc），不新增语言特性。
3. nativecc（自研 C 编译器）仅服务于 C 后端，随 C 后端一并删除；`--cc=native` 参数废弃。
4. 生成的是**文本 LLVM IR（.ll）**，默认 target `x86_64-pc-windows-msvc`；`--emit-llvm` 只落 IR，`--emit-exe` 走 clang 全链。
5. 第30轮未提交改动视为本轮基线，先提交断点再动刀。

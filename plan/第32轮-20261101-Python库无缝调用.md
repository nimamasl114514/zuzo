## 显式假设

1. 「无缝」= 用户不需要知道进程边界：`.hy` 里 `py导入("numpy")` 直接拿到可用句柄；`py执行("import numpy as np")` 在老代码里命中 C 扩展时自动改走子进程并继续跑。
2. 「py 的库」= 本机 CPython 已安装的库（site-packages）；缺库时提供显式 `py安装(包名)`（走 `python -m pip install`，非自动、非隐式联网）。
3. 句柄是「引用语义」，zuzo 侧原生容器跨桥是「快照语义」（与既有 mix 桥一致，文档写明）。
4. 兼容性优先：现有 `py求值 / py执行 / py调用 / py获取 / py设置 / py存在` 行为不变；新能力只新增内置名，不改老语义（C 扩展降级是唯一增强点）。
5. 构建用 `CGO_ENABLED=1 CC="/c/Dev/zig/zig cc"`（本机无 gcc，zig 0.16.0 在 `/c/Dev/zig/zig.exe`）。

## 协议契约（子代理 A / B / C 共用，实现以本节为准）

### 传输

- 子进程启动命令：`<python> -u <child.py 路径> --stdio`
- **stdin/stdout 专用于协议，一行一条 JSON**（UTF-8，`\n` 结尾）；子进程把用户 `print()` 重定向到 **stderr**。
- 请求：`{"id":N,"op":"<名字>", ...}`
- 成功：`{"id":N,"ok":true,"v":<enc>}`
- 失败：`{"id":N,"ok":false,"e":{"t":"ImportError","m":"No module named 'xx'","tb":"Traceback ..."}}`

### 值编码 `enc`

| Python 值 | enc |
|---|---|
| None | `{"k":"none"}` |
| bool | `{"k":"bool","v":true}` |
| int | `{"k":"int","v":"-123"}`（十进制字符串，避免 JSON 精度丢失） |
| float | `{"k":"float","v":1.5}`；inf/nan → `{"k":"float","v":"inf"}` / `"nan"` |
| str | `{"k":"str","v":"文本"}` |
| bytes/bytearray | `{"k":"bytes","v":"<base64>"}` |
| list/tuple/range/set/frozenset | `{"k":"list","v":[enc...]}`（set 按迭代顺序） |
| dict | `{"k":"dict","v":[[enc,enc],...]}` |
| numpy 标量（`shape==()`） | 标量 enc（item()） |
| numpy ndarray（`size<=200000`） | `{"k":"list","v":[...]}`（`.tolist()` 嵌套） |
| numpy ndarray（更大） | `{"k":"obj", ...}` 句柄 |
| 其余对象（含 DataFrame/Series/模块/类实例/函数） | `{"k":"obj","id":N,"t":"类型名","r":"repr 前 200 字符"}`；可调用对象用 `"k":"call"` 同结构 |

### ops

| op | 参数 | 返回 |
|---|---|---|
| `hello` | — | `{"py":"3.12.13","exe":"C:/...","impl":"CPython"}` |
| `import` | `name` | 模块句柄 enc |
| `get` | `id`,`name` | enc |
| `set` | `id`,`name`,`v` | `{"k":"none"}` |
| `call` | `id`,`args`:[enc],"kwargs":{str:enc} | enc |
| `eval` | `expr` | enc（在常驻 globals 求值） |
| `exec` | `code` | `{"k":"none"}`（写常驻 globals） |
| `repr` | `id` | `{"k":"str"}` |
| `native` | `id` | 尽力转原生：ndarray→tolist、DataFrame→records、Series→list、set/tuple→list、bytes→b64、标量→标量；失败则原样 enc |
| `release` | `id` | none |
| `has` | `name` | `{"k":"bool"}`（`importlib.util.find_spec` 探测，不实际导入） |
| `ping` | — | `{"k":"str","v":"pong"}` |
| `shutdown` | — | 进程退出 0 |

### 句柄表

- 子进程侧 `dict[int, object]`，自增 ID 从 1 起；`release` 释放；进程退出即全释放。
- 建议在 child.py 里加 `--selftest`：跑一遍 hello/ping/import json/eval/call/get/native/错误路径，打印 `SELFTEST PASS n`。

## 计划修订（本轮实际偏航记录）

1. **`ndarray` 编码口径改了**：原契约写「`size<=200000` 内联成 zuzo 数组」，实测发现内联后 `a.sum()` 一类方法全丢，`py方法(a,"sum")` 直接报 E913。改为**一律给句柄**，要原生数组显式 `py取值(h)`；文档与用例（t03/t04）同步改。
2. **降级判定从看 ImportError 改为看症状集合**：numpy 的 `__init__.py` 是纯 Python，真炸点是 `AttributeError: module 'os' has no attribute 'add_dll_directory'`（delvewheel 补丁），只判 `C extension` 抓不到 → 新增 `shouldFallback()`。
3. **内置从 12 个加到 14 个**：`py调参`（关键字参数通道，pandas/json 必备）与 `py类型`（远端类型名，`py描述` 只给 repr 不够判类型）。
4. **`py取值` 加两参形式**：`py取值(df, "a")` = `df["a"]`，pandas 取列高频，省一次 `py方法(...,"__getitem__",...)`。
5. **子代理 B 未交付 runner**（只落 7 个用例、无 `run_tests_bridge.sh`），主代理补齐 runner + 6 个用例 + `.expected`；子代理 C 的文档基于「计划契约」而非实现，主代理按实测重写 `docs/python-bridge.md` 并修正 interop/capability 两处口径。

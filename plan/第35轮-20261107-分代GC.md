# 第35轮 · 分代 GC（两代 mark-sweep）· 2026-11-07

## 目标

把 LLVM AOT 产物侧的第27轮「单链全堆 mark-sweep」升级为**两代分代 GC**：
年轻代高频回收、老年代低频回收、存活对象按年龄晋升，保持精确根集契约与零语义漂移。

## 现状（第27轮）

`llvmbackend/runtime/zuzo_rt.c`：单条 `z_gc_head` 对象链，`z_gc_safepoint()` 在
`live_bytes >= threshold` 时整堆标记 + 清扫，阈值回收后 `max(4MB, 2*live)`。
问题：所有对象同权，短命临时对象与长寿命对象混在一条链上，每次回收都要扫全堆。

## 设计

| 项 | 决策 |
|---|---|
| 代数 | 2 代：年轻代（gen=0）/ 老年代（gen=1），两条独立对象链 |
| 晋升 | 历经 `Z_GC_PROMOTE_AGE=2` 次年轻代回收仍存活 → 移入老年代 |
| minor | 只清扫年轻代；**老年代整体当隐式根**（零写屏障，杜绝漏标误回收；代价是标记阶段扫老年代） |
| major | 整堆标记 + 双链清扫；年轻代存活者直接晋升 |
| 标记 | epoch 计数（`o->mark == z_gc_epoch` 即可达），每轮免清零 |
| 阈值 | young 初始 1MB；old 初始 8MB，major 后 `max(8MB, 2*old_live)` |
| 兼容 | `ZUZO_GC=off`、`z_gc_set_enabled`、`z_gc_set_threshold`、`z_gc_stats` 四参签名全部保留 |
| 观测 | `ZUZO_GC_TRACE=1` → stderr 输出 `[gc] minor/major ...` 行；新增 `z_gc_gen_stats()` C API |

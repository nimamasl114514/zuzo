# zuzo 混合语言源文件（.hypy）

一个文件里同时写 **zuzo（中文语法）** 与 **Python**，顺序执行、共享输出、双向调用、全局表互通。

```hypy
// 混合文件示例
##PY
def 问候(名字):
    return "你好, " + 名字
##ZUZO
变量 结果 = py调用("问候", "世界")
打印(结果)
```

```bash
zuzo examples/mixed_demo.hypy
```

## 1. 文件格式

| 项 | 规则 |
|---|---|
| 扩展名 | `.hypy` |
| 块标记 | 整行（忽略首尾空白）为 `##ZUZO` 或 `##PY`，大小写不敏感；`##HY` / `##PYTHON` 亦接受 |
| 默认块 | 未出现任何标记时，整文件按 **zuzo** 执行（宽容回退） |
| 首块之前 | 只允许空行与注释（`//`、`#` 开头）；出现代码即报错并给出行号 |
| 空块 | 内容全为空白时不执行，不报错 |

块标记本身不会进入任何语言的词法器，因此不会造成语法错误。

## 2. 执行语义

1. **顺序执行**：按块在文件中的出现顺序逐块执行，前一块出错立即停止并返回非零退出码。
2. **共享输出**：两种语言都写到同一个 stdout / stderr，输出顺序即执行顺序。
3. **行号对齐**：块解析前会用空行填充到其在原文件中的起始行，因此语法错误、异常 traceback 的行号一律是 **原文件行号**（不是块内相对行号）。
4. **单实例**：整个文件只有 **一个 Python 解释器实例** 和一个 **一个 zuzo 全局环境**，跨块状态连续。
5. **执行引擎**：混合模式统一走纯 Tree-Walk（关闭 SAP 槽位优化），避免跨块槽位失效。

## 3. 双向调用

| 方向 | API | 说明 |
|---|---|---|
| zuzo → Python | `py调用("函数名", 参数...)` | 调 Python 全局或内置函数 |
| zuzo → Python | `py获取("变量名")` | 取 Python 变量（函数会包装成 zuzo 可调用对象） |
| zuzo → Python | `py设置("变量名", 值)` | 写 Python 全局变量 |
| zuzo → Python | `py存在("变量名")` | 判断 Python 侧是否存在该名字，返回布尔 |
| Python → zuzo | `zuzo.调用("函数名", 参数...)` | 调 zuzo 函数 |
| Python → zuzo | `zuzo.获取("变量名")` | 取 zuzo 变量 |
| Python → zuzo | `zuzo.设置("变量名", 值)` | 写 zuzo 全局变量 |
| Python → zuzo | `zuzo.存在("变量名")` | 判断 zuzo 侧是否存在该名字 |

高阶用法（函数作为参数跨语言传递）已支持：

```hypy
##PY
def 映射(函数, 列表):
    return [函数(v) for v in 列表]

def 翻倍(v):
    return v * 2
##ZUZO
变量 结果 = py调用("映射", py获取("翻倍"), [1, 2, 3])
打印(结果)   // [2, 4, 6]
```

## 4. 全局表同步

- **时机**：每块执行结束后做一次双向同步。
- **方向**：Python 块结束 → 同步到 zuzo 环境；zuzo 块结束 → 同步到 Python 全局表。
- **冲突**：同名变量 **后定义覆盖**（后执行的块拥有最终值）。
- **拷贝语义**：标量与容器为 **深拷贝快照**；块内修改自身语言的对象不会自动回写到对方语言（需要时用 `py设置` / `zuzo.设置` 显式写回）。
- **跳过项**：Python 的模块、类、实例、方法对象；zuzo 的内置函数（含桥注入项）、模块、蓝图、错误对象。这些对象无对等语义，不参与同步。

## 5. 类型映射

| zuzo | Python | 备注 |
|---|---|---|
| 整数 | int | Python 大整数超出 int64 时降级为 zuzo 字符串，避免静默丢精度 |
| 浮点数 | float | — |
| 字符串 | str | — |
| 布尔 | bool | — |
| 空 | None | — |
| 数组 | list / tuple | 双向都转成数组 / 列表 |
| 哈希 | dict | 保持插入顺序 |
| 函数 / 内置 | 可调用代理 | 双向包装，调用时跨回原侧执行 |

## 6. 已知限制

1. 混合模式关闭 SAP 优化（性能路径不同），单语言 `.hy` / `.py` 不受影响。
2. 容器为深拷贝快照；跨语言共享「同一个可变对象」需显式读写。
3. Python 的类 / 实例 / 模块无法进入 zuzo 侧运算，只作为只读摘要字符串出现。
4. zuzo 出错时若发生在块边界之前，后续块不执行（与单语言语义一致）。
5. 混合文件不支持 `--shadow` 影子模式（该模式依赖单语言双轨）。

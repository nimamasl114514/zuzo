# 字符串标准库（`文本`）

> 版本：1.0.0（2026-10-25 · 第18轮重构）
> 成员：**110 个**（9 个能力组）· 高层封装库：`libs/strings`（16 个复合函数）
> 测试：Go 单测 `evaluator/strlib_test.go`（9 个测试函数 / 160+ 断言）+ 端到端 BDD `tests/strlib_test.hy`（23 用例 / 116 断言）

---

## 0. 一页速览

```zuzo
// 内建命名空间：零导入，直接可用
打印(文本.大写("hello"))                 // HELLO
打印(文本.子串("你好世界", 1, 3))          // 好世
打印(文本.显示宽度("你好ab"))              // 6
打印(文本.中文数字("一百二十三"))           // 123
打印(文本.按宽度填充("你好", 8, "-", "中")) // --你好--

// 高层封装库：导入后使用复合能力
导入 "libs/strings/main.hy" 为 串
打印(串.统计("你好 world"))                // {字符数: 8, 字节数: 12, 显示宽度: 9, ...}
打印(串.千分位(1234567))                   // 1,234,567
打印(串.表格([["姓名","城市"],["张三","北京"]], [0, 0], " | "))
```

**两条设计原则**：

1. **底层原子能力在 Go 里**：UTF-8/Unicode 正确性、rune 语义、东亚宽度、性能敏感操作，一律用 Go 实现（`evaluator/strlib_*.go`）。
2. **复合能力用 zuzo 自己写**：统计、表格、命名法、模板、行处理这类"由原子操作组合而成"的能力放 `.hy` 库（`libs/strings`），既 dogfooding 又便于用户按需改写。

## 1. 为什么叫 `文本` 而不是 `字符串`

`字符串` 已经是全局类型转换内置函数：

```zuzo
打印(字符串(42))    // "42"
```

如果命名空间也叫 `字符串`，`字符串(42)` 会被模块对象覆盖，破坏既有代码。故命名空间取 **`文本`**：

```zuzo
打印(文本.转文本(42))   // "42"（命名空间内的转换入口）
```

> 这是第18轮开工对齐时确认的显式假设之一（Q2 = 混合形态，命名空间名由实现侧定）。

三步，核心零改动：

```go
// 1. 在对应分组文件里加实现（例如 strlib_zh.go）
func strMyNew(args ...object.Object) object.Object {
    if e := argc("我的新方法", args, 1, 1); e != nil {
        return e
    }
    s, e := argStr("我的新方法", args, 0, "")
    if e != nil {
        return e
    }
    return strObj(s + "!")
}

// 2. 在该文件的 init() 注册表里加一行
registerStringMethods(map[string]object.BuiltinFunction{
    "我的新方法": strMyNew,
})

// 3. 加测试（evaluator/strlib_test.go 的对应 Test 表里加一行）
{"我的新方法", strMyNew, os_("hi"), "hi!"}
```

命名空间自动出现 `文本.我的新方法`，无需改 `evaluator.go` / `registerBuiltins`。

## 9. 边界与限制

1. **不支持切片语法**：`s[0:3]` 会报错（zuzo 索引表达式不支持字符串），用 `文本.子串(s, 0, 3)`。
2. **`查找` 系列返回 rune 下标**，不是字节下标；需要字节偏移时用 `文本.utf8字节数(文本.子串(s,0,i))` 换算。
3. **`替换字符` 的映射键必须是单字符**，多字符键会报错。
4. **`中文数字` 支持到「万亿」量级**，超过会丢精度（int64 边界）。
5. **`显示宽度` 对 emoji 按 EastAsianWidth 判定**：大部分 emoji 计 2 列，但 ZWJ 组合序列（家庭/肤色）会被逐码点计算，可能偏宽。
6. **`按宽度填充` 用「向上取整」补齐**：填充串本身宽度 > 1 时，实际结果可能比目标宽 1 列。

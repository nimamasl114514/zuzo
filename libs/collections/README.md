# Collections 库 (1.0.0)

Zuzo 集合工具库，提供栈、队列、数学工具等常用数据结构与算法。

## 模块函数

### 栈 (Stack LIFO)
| 函数 | 说明 |
|------|------|
| `新建栈()` | 创建空栈 `{"数据": [], "大小": 0}` |
| `栈压入(栈, 元素)` | 压入栈顶 |
| `栈弹出(栈)` | 弹出并返回栈顶元素 |
| `栈查看(栈)` | 查看栈顶（不弹出） |
| `栈是否为空(栈)` | 检查是否为空 |
| `栈清空(栈)` | 清除所有元素 |

### 队列 (Queue FIFO)
| 函数 | 说明 |
|------|------|
| `新建队列()` | 创建空队列 |
| `入队(队列, 元素)` | 添加到队尾 |
| `出队(队列)` | 取出并返回队首 |
| `队列查看(队列)` | 查看队首（不取出） |
| `队列是否为空(队列)` | 检查是否为空 |
| `队列清空(队列)` | 清除所有元素 |

### 数学工具
| 函数 | 说明 |
|------|------|
| `最大值(数组)` | 返回数组最大值 |
| `最小值(数组)` | 返回数组最小值 |
| `求和(数组)` | 计算数组元素和 |
| `平均值(数组)` | 计算平均值 |
| `阶乘(n)` | 计算 n! |
| `是否为素数(n)` | 判断素数 |
| `生成素数(n)` | 生成 n 以内素数列表 |
| `范围(起始, 结束)` | 生成整数范围数组 |

## 使用方式

```zuzo
导入 "collections.z" 为 集合

// 使用栈
变量 s = 集合.新建栈()
集合.栈压入(s, 10)
集合.栈压入(s, 20)
打印(集合.栈弹出(s))  // 输出: 20

// 使用队列
变量 q = 集合.新建队列()
集合.入队(q, "任务A")
打印(集合.出队(q))  // 输出: 任务A

// 使用数学工具
变量 数 = [3, 1, 4, 1, 5, 9, 2, 6]
打印("最大值:", 集合.最大值(数))
打印("平均值:", 集合.平均值(数))
```

## 打包与分发

# 打包
cd libs/collections

# 查看
zpm inspect collections-1.0.0.z

# 安装到其他项目
